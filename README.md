# F1 Live Timing

An Android app to follow Formula 1 sessions, with live timing, championship standings and race-weekend results.

## Features

### Live timing
- Live session status and timing data from the configured backend.
- Driver leaderboard and timing information.
- Session lap count and race-control / track-status information.
- Track weather.
- Tyre compounds and stint details.

### Championship standings
- View the drivers' and constructors' championships.

### Calendar and session results
- Browse the race calendar by season.
- View race results, qualifying, sprint results, sprint qualifying and practice timings.

## Data backend

The repository includes a Docker setup for [`julesr0y/f1-livetiming-api`](https://github.com/julesr0y/f1-livetiming-api). It provides the live timing API consumed by the app.
